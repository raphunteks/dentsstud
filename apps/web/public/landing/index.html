Tanya jawab tentang DENTSWEB STUDIO

Apakah saya perlu akun Claude?

Ya. Hubungkan API key Anthropic milik Anda, atau Claude Code resmi di aplikasi desktop. Koneksi tidak dipakai bersama member lain.

Berapa biayanya?

DENTSWEB STUDIO berlisensi nonkomersial yang diberikan Superadmin. Pemakaian Claude dan layanan suara ditagih ke akun Anda sendiri.

Apakah fakta di video diperiksa?

Agent cek fakta membandingkan setiap klaim naskah dengan sumber riset. Klaim tanpa bukti ditandai belum terverifikasi sebelum render.

Bisakah suara diganti setelah video jadi?

Bisa. Dari menu Hasil Anda dapat mengganti suara, mengunggah rekaman sendiri, atau merender ulang tanpa mengulang riset.
